## 📌 Project Overview

This project uses Machine Learning to analyze applicant data and predict loan approval status.

## 💡 Features

- Machine Learning model (Random Forest)
- Interactive Streamlit web app
- Loan approval prediction
- Probability scoring (approval/rejection)
- Risk level classification (Low / Medium / High)
- User-friendly UI with dropdowns
- Real-time predictions
